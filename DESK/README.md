# `PQTR:DESK`

This is the desktop GUI for `LABS`.

*   It will serve as a visual editor and viewer for the `pipe`.
*   It will provide a user interface for the `tune` optimization process.
*   The initial version will be a refactor of the old, deprecated `tune` GUI tool.
*   It will use native OS graphics APIs and will not have a dependency on OpenCL.
